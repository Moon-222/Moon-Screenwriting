## 剧本
**·阅读须知**
目前库里只有两个剧本。
**剧本一**为大二的原创期末作品———独幕剧《塔纳托斯》改编而来。笔者共进行了两个版本的改写。两版本质都是互动式叙事，但第二版的自由度更高。
- 版本一的剧本可被定义为视觉小说式叙事。剧情基本保留原作的内容和框架，只是增添了一些影响数值的对话，这些数值会影响后续的结局判定。（可参考橙光游戏/互动小说的形式）。

- 版本二的改编则更倾向于RPG设定。但由于原作的体量较小，且内容结构方面还存在些许弊病，因而这一版的改动还在开发中（一稿大体完成，但还需要进行大幅度调整）

**剧本二**还未产出成型剧本。因为一次偶然间看到“法兰西举全国财力赎回国王，而他却在新一轮的战争途中腹泻而死”[^1]而产生灵感：如果有一位幻想成为伟大骑士的贵族少女，因为无法忍受家族的联姻而出逃加入十字军，在赎回国王的途中见到了人情冷暖，她的信仰是否会动摇？所谓的圣战，真的是正义的吗？
目前已经梳理了主要人物的动机和主线脉络，还写了几个切片场景与人物小传。（参考巫师三/天国拯救系列）
[^1]: 出自《如何屠龙：中世纪英雄冒险指南》一书，原文为：整支十字军队伍被俘，光是赎回国王一个人就得耗掉法国全国年收入的三分之一，这样一场东征很难称得上成功。难上加难的是，这位国王在另一次东征中率军远赴突尼斯，却迅速因可怕的腹泻离世。
